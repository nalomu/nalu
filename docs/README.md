# Nalu 文档

Nalu 是一个本地优先的个人助手应用，基于 Tauri 2、Vue 3、Pinia、TypeScript 和 Rust 构建。

这套文档把已有长文档拆成更容易查阅的入口：

- **指南**：本地开发、手机端预览和日常调试。
- **功能**：闹钟、番茄钟、声音设置、首页仪表盘等用户侧设计。
- **开发**：架构、Tauri commands、数据与平台差异。
- **运维**：Android 构建、Gradle/NDK 缓存迁移和机器环境。
- **归档**：保留较长的 PRD、技术栈、实现细节和复盘原文。

## 常用命令

```bash
pnpm docs:dev
pnpm docs:build
```

## 当前重点

- 闹钟关闭后必须能停止所有声音实例。
- 番茄钟开始、番茄钟结束、全局闹钟和单个闹钟都支持独立铃声。
- 番茄钟和闹钟共用一个音量设置。
- Android 构建环境使用外置盘上的 SDK/NDK，Gradle 缓存也迁移到外置盘。
