# 闹钟、番茄钟与铃声

## 目标

提醒类能力要做到三件事：

- 用户在任意页面都能收到提醒。
- 点击关闭后，所有正在响的声音实例都必须停止。
- 铃声和音量设置足够直观，不需要进入深层页面才能调整。

## 声音类型

当前声音设置拆成四类：

| 类型 | 用途 |
|------|------|
| 番茄钟开始 | 点击开始专注时播放 |
| 番茄钟结束 | 工作或休息阶段结束时播放 |
| 默认闹钟 | 未单独设置铃声的闹钟使用 |
| 单个闹钟铃声 | 覆盖默认闹钟铃声 |

番茄钟和闹钟共用一个音量值，避免用户在多个页面重复调整。

## 自定义铃声

用户选择本地音频文件后，应用会把文件复制到应用数据目录下的 `sounds` 目录。这样后续播放不依赖原文件是否还在下载目录或桌面。

支持的格式：

- `mp3`
- `wav`
- `ogg`
- `m4a`
- `aac`
- `flac`

## 播放与停止原则

- 循环铃声只保留一个活跃音频实例。
- 关闭提醒时同时停止当前 WebView 音频，并广播全局停止事件。
- 所有旧循环都必须能被代际计数器中止，避免隐藏窗口或重复事件产生孤儿声音。
- Tauri 后端提醒事件默认发给 `main` 窗口，避免多 WebView 重复注册监听。

## 推荐铃声设计

提醒音不应该只是一声短 beep。建议准备三类默认音：

- **轻提示**：番茄钟开始，短、柔和、低干扰。
- **阶段完成**：番茄钟结束，比开始音更明确，但不需要持续循环。
- **闹钟**：可循环、辨识度高、频率不刺耳，适合用户必须处理的提醒。

自定义铃声保存时只保存文件路径和显示名称；数据库中的单个闹钟只存覆盖配置，不复制全局设置。
