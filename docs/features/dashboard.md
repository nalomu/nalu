# 首页仪表盘

## 定位

首页不是营销页，而是用户每天打开应用后最先操作的工作台。

## 当前首页职责

- 展示任务、笔记、日程等核心数据摘要。
- 提供常用模块入口。
- 把高频设置前置，例如提醒音量。
- 提供番茄钟快速开始/暂停。
- 提供剪贴板监听开关。
- 支持编辑首页控制区域位置，让用户按自己的使用习惯整理工作台。

## 设计原则

- 高频操作放首页，低频配置留在设置页。
- 首页控件不复制完整功能，只提供最常用的一步操作。
- 移动端优先保证可读、可点、无横向滚动。
- 声音控制只暴露统一音量和试听，详细铃声选择仍在设置页和闹钟页。
- 布局编辑只调整区域顺序，不改变区域内部业务逻辑。

## 可编辑区域位置

仪表盘提供“编辑布局”模式。进入后，每个主要控制区域会显示拖动手柄，用户可像整理手机桌面一样拖动区域改变顺序。

布局顺序保存在本地 `localStorage` 的 `nalu-dashboard-widget-order-v1`，重新打开应用后保持。点击“恢复默认”可回到内置顺序。

首期支持排序的区域包括：快捷控制、快捷导航、专注与最近要处理、闹钟、数据统计、剪贴板、最近要处理、最近笔记和 AI 助手。
